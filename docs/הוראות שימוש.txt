YouTube Proxy — הוראות הקמה
================================

מה זה: תוסף כרום שמוריד סרטונים (או ערוצים שלמים) דרך GitHub Actions במקום דרך
שרת. אתה שולט בהכל דרך הריפו שלך בגיטהאב — אין שרת מרכזי ואין תלות באף אחד.

התיקייה הזו היא עותק נקי, בלי שום פרט אישי של מי ששלח לך אותה — לא שם משתמש,
לא טוקן ולא מפתח הצפנה. כדי שזה יעבוד אצלך צריך להקים ריפו וטוקן משלך; זו עבודה
חד-פעמית של כ-10 דקות.


שלב 1 — יצירת ריפו
--------------------
1. היכנס ל-github.com וצור ריפו חדש, **ציבורי** (Public). זה חשוב: ריפו ציבורי
   מקבל דקות הרצה חינמיות ללא הגבלה ב-GitHub Actions.
2. העלה לריפו את כל התוכן של התיקייה הזו (חוץ מקובץ ההוראות הזה). עם git:

       git init
       git add .
       git commit -m "initial"
       git branch -M main
       git remote add origin https://github.com/<שם-המשתמש-שלך>/<שם-הריפו>.git
       git push -u origin main


שלב 2 — secret בשם COOKIE_KEY
-------------------------------
הריפו ציבורי, ולכן עוגיות היוטיוב שהתוסף שולח מוצפנות (AES-256-GCM) לפני שהן
יוצאות מהמחשב. צריך מפתח אחד שיושב גם בגיטהאב וגם בתוסף.

1. הפק מפתח אקראי:

       python -c "import secrets; print(secrets.token_hex(32))"

2. בריפו: Settings ← Secrets and variables ← Actions ← New repository secret.
   שם: COOKIE_KEY. ערך: המפתח שהפקת.
3. את אותו ערך תכניס בשלב 4 בשדה cookieKey.


שלב 3 — טוקן גישה
-------------------
צריך Personal Access Token מסוג fine-grained עם הרשאה **אחת בלבד**:

  - Repository access: Only select repositories ← הריפו שיצרת בשלב 1
  - Permissions ← Actions: Read and write

זה מספיק כדי להפעיל את הוורקפלואו, לעקוב אחרי ריצה ולהוריד את הקובץ — ולא נותן
שום גישה אחרת (לא לקוד, לא ל-secrets, לא לריפואים אחרים). מפיקים כאן:
https://github.com/settings/personal-access-tokens/new


שלב 4 — הגדרות התוסף
-----------------------
1. בתיקייה extension/ העתק את config.example.js לקובץ חדש בשם config.js.
2. פתח את config.js ומלא:
     owner     ← שם המשתמש שלך בגיטהאב
     repo      ← שם הריפו שיצרת
     cookieKey ← המפתח משלב 2 (64 תווי hex)
3. את הטוקן משלב 3 הכי נוח להטמיע עם הסקריפט (מהתיקייה הראשית):

       python tools/embed_token.py

   הוא מבקש להדביק את הטוקן (הקלט מוסתר), בודק מול גיטהאב שהוא באמת עובד, וכותב
   אותו ל-config.js לא כמחרוזת גלויה אלא מפוצל ומעורבב עם XOR, כדי שלא יופיע
   כמחרוזת קריאה אחת. חשוב להבין: זה טשטוש ולא הצפנה אמיתית — המפתח יושב באותו
   קובץ. ההגנה האמיתית היא ההרשאה המצומצמת של הטוקן משלב 3.

   אפשר גם להדביק אותו ידנית בשדה token. בכל מקרה config.js נשאר רק אצלך —
   הוא ב-.gitignore ולא עולה לגיטהאב.

טיפ: יש גם tools/new_account.py שעושה את כל שלבים 1-4 אוטומטית (יוצר ריפו,
דוחף קוד, מגדיר secret, בונה תיקייה מוכנה) — צריך רק טוקן עם הרשאה ליצור ריפו.


שלב 5 — טעינת התוסף בכרום
----------------------------
chrome://extensions ← מצב מפתח (Developer mode) ← "טעינת פריט לא ארוז"
(Load unpacked) ← בחר את התיקייה extension/.

חשוב: צריך לבחור **תיקייה**, לא קובץ ZIP. אם הורדת ZIP — חלץ אותו קודם.


שימוש
------
* לחיצה על אייקון התוסף פותחת לשונית קבועה. אפשר לסגור אותה — ההורדות ממשיכות
  ברקע וממשיכות מאיפה שהיו כשחוזרים.
* בדף סרטון ביוטיוב מופיע כפתור "הורדה" בשורת הכפתורים (ליד "שיתוף"). אם יש לך
  YouTube Premium, הכפתור שלנו מחליף את כפתור ההורדה המקורי; אם אין לך — הוא
  מופיע בכל מקרה. לחיצה פותחת תפריט בחירת איכות.
* קישור לערוץ או לפלייליסט מזוהה אוטומטית ומוריד את כולו כ-ZIP אחד. אם לערוץ יש
  פלייליסטים משלו (אלבומים, לייב וכו') הם הופכים לתיקיות בתוך ה-ZIP.
* בזמן משיכת הקובץ מגיטהאב מוצג קישור ישיר שאפשר להעתיק ל-IDM. שים לב שהוא
  חתום ובעל תוקף קצר — אחרי כמה דקות הוא יפוג.


דברים שכדאי לדעת
-------------------
* יוטיוב חוסם הורדות מכתובות ה-IP של GitHub בלי עוגיות של חשבון מחובר. התוסף
  שולח את העוגיות שלך אוטומטית (מוצפנות); בלי זה כל הורדה מיוטיוב תיכשל עם
  "Sign in to confirm you're not a bot". עדיף חשבון גוגל נפרד ולא הראשי שלך.
* הריפו ציבורי ⇒ גם קבצי ה-artifact ציבוריים. מי שיש לו קישור לריצה יכול להוריד
  את הקובץ במשך יום (retention-days: 1). העוגיות מוצפנות, הסרטון עצמו לא.
* עד 200 פריטים לערוץ, עד 16 הורדות במקביל (מגבלה של גיטהאב).
* טוקן שדלף = נזק מוגבל: הוא יכול רק להפעיל/לבטל ריצות ולהוריד artifacts בריפו
  הזה בלבד. לביטול: https://github.com/settings/personal-access-tokens
