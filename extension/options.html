ההורדה רצה ב-GitHub Actions ולא במחשב שלכם. התוסף רק שולח את הקישור והעוגיות, ומושך את הקובץ בסיום.

ריפו

אבטחה

הריפו ציבורי, ולכן העוגיות נשלחות מוצפנות (AES-256-GCM) ומפוענחות רק בתוך הריצה עצמה. הטוקן וה-COOKIE_KEY נשמרים רק בדפדפן הזה ולא נשלחים לשום מקום מלבד api.github.com.

איך מפיקים טוקן

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. תחת Repository access בוחרים Only select repositories ומסמנים את הריפו הזה בלבד, ותחת Permissions מגדירים Actions: Read and write — וזו ההרשאה היחידה שנדרשת.
